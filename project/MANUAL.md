## ✅ まず結論

- **ブラウザ更新だけでは反映されません。**
- 理由:
  - 画面（Reactコード）を変更しているため → **Vercel再デプロイが必要**

## 📅 予約確認表（月間）使い方マニュアル

ホーム画面（TOP）のいちばん上にある **「予約確認表（月間）」** の操作説明です。  
紙の予約表の代わりに、ここで予約の確認・登録・来院入力へのつなぎを行います。

---

### この画面でできること（5つだけ覚えればOK）

| やりたいこと | 操作 |
|-------------|------|
| 予約を見る | カレンダーで月をめくる |
| 予約を入れる | 日付をタップ |
| 予約を直す・消す | 予約の行（チップ）をタップ |
| 来院入力を始める | 予約編集画面の **「来院入力へ」** |
| 特定の人だけ見る | 上の検索欄に名前・かな・番号を入れる |

---

### 画面の見方

```
┌─────────────────────────────────────────┐
│  予約確認表（月間）    ◀  2026年6月  ▶   │  ← 左右の矢印で月を変える
│  [高槻] [川西] [全体]  検索欄…  [予約追加] │
├─────────────────────────────────────────┤
│  日  月  火  水  木  金  土              │
│ ┌──┬──┬──┬──┬──┬──┬──┐              │
│ │ 1│ 2│ 3│ …│                    │  ← 各マス＝1日
│ │  │10:00 5123 山田│              │
│ └──┴──┴──┴──┴──┴──┴──┘              │
│  入力メニュー（来院入力・物販・サブスク）   │  ← カレンダーの下
└─────────────────────────────────────────┘
```

- **今日の日付** … 枠が少し色付き（見分けやすくなっています）
- **予約の行（チップ）** … `10:00 5123 山田太郎` のように  
  **時間 → 顧客番号 → 名前** の順で表示されます
- 1日に予約が4件以上あると **「他◯件」** と表示されます（全部見るにはその日をタップして編集画面から確認）

---

### 予約の色の意味

| 色 | 意味 |
|----|------|
| 青っぽい | **予約**（これから来る予定） |
| 緑っぽい | **来院済**（もう来た・来院入力も済んだ） |
| グレー＋取り消し線 | **取消**（キャンセルした予約） |

---

### 操作① 予約を確認する

1. 画面下の **「ホーム」** を押す（TOPに戻る）
2. 上の **「予約確認表（月間）」** を見る
3. **◀ ▶** で見たい月に変える
4. 院で絞りたいときは **高槻 / 川西 / 全体** を押す

> **全体** … 両院まとめて表示  
> **高槻 / 川西** … その院の予約だけ表示

---

### 操作② 予約を新しく入れる

**方法A（日付から入れる・おすすめ）**

1. 予約したい **日付のマス** をタップ
2. 出てきた画面で **顧客を検索して選ぶ**  
   - 来院入力と同じ検索（**氏名・かな・顧客番号**）
3. **予約日・開始・終了** を確認・入力  
   - 時間は **15分刻み固定ではありません**（例: 10:00〜10:45 もOK）
   - **終了は開始より後** にしてください
4. 必要なら **メモ** を書く
5. **「保存」** を押す

**方法B（ボタンから入れる）**

1. 右上の **「予約追加」** を押す
2. 以降は方法Aと同じ

> 顧客を選ぶと、顧客番号から **院（高槻/川西）が自動で入る** ことが多いです。  
> 必要なら「院」のプルダウンで変更できます。

---

### 操作③ 予約を直す・消す

1. カレンダー上の **予約の行（チップ）** をタップ  
   ※ 日付マス全体ではなく、**予約の行だけ** タップ
2. **「予約を修正」** 画面が開く
3. 内容を直して **「保存」**
4. 消すときは **「削除」** → 確認で OK

**状態を手動で変えたいとき（編集画面のみ）**

- **予約** … これから来る
- **来院済** … もう来た（手動で付け替えも可能）
- **取消** … キャンセル

---

### 操作④ 予約から来院入力へ（いちばん便利）

患者さんが来たときの流れです。

1. 予約の行をタップ → **「予約を修正」** を開く
2. **「来院入力へ」**（青いボタン）を押す
3. **来院入力** 画面に移る  
   - **顧客** … 自動で選ばれた状態  
   - **来院日** … 予約日が入った状態  
   - **来院入力** パネル … 最初から開いている
4. いつもどおり金額・メニューなどを入力して **登録**
5. 登録が成功すると、予約は **自動で「来院済」** になります

> 予約から来た場合、来院登録と予約が **自動でつながります**。  
> わざわざ予約を「来院済」にし直す必要はありません（登録成功時に自動更新）。

---

### 操作⑥ 「予約以外」タブ（空き・その他）

院別の左に **「表示: 予約 | 予約以外」** があります。

| タブ | 用途 | 色 |
|------|------|-----|
| **予約** | 患者さんの予約（顧客あり） | 青 / 緑 / グレー |
| **予約以外** | 空き（Vacant）・その他の枠（顧客なし） | 黄 / 紫 |

1. **「予約以外」** をタップ
2. 日付タップ → **枠を追加**
3. **種類** … 空き（Vacant）または その他
4. **表示名** … カレンダーに出る文字（例: 空き / 昼休み）
5. 院・時間を入れて **保存**

> **来院入力の記録はどちらのタブにも自動では出ません。**  
> カレンダーに載せたい過去分は、予約または枠として手動登録してください。

---

### 操作⑤ 名前・番号で予約だけ絞り込む

1. カレンダー上の **「氏名・かな・番号で絞り込み」** に入力
2. 例: `やまだ` / `5123` / `山田` など
3. カレンダーに **該当する予約だけ** 表示されます

来院入力と同じルールで、**かな（ひらがな・カタカナ）** でも検索できます。

### よくある質問（予約確認表）

**Q. 日付をタップしたら予約追加になってしまう。編集したかったのに…**  
→ 予約を直すときは **日付マスではなく、予約の行（チップ）** をタップしてください。

**Q. 6/1に来院入力したのにカレンダーが白い**  
→ **来院記録と予約は別データ** です。来院入力を直してもカレンダーには出ません。  
  カレンダーに載せたい場合は **「予約」タブで予約追加** してください（過去日付も可）。

**Q. 予約と来院記録は同じ？**  
→ **別物** です。予約は「これから来る予定」、来院記録は「実際に施術した記録」です。  
  「来院入力へ」→ 来院登録すると、予約側が **来院済** に更新されます。

**Q. 予約なしで来院入力だけしたい**  
→ カレンダーの下 **「来院入力」** ボタンから、いつもどおり入力してください。

**Q. 時間は何分単位？**  
→ **自由** です。開始・終了をそれぞれ選べます（例: 9:30〜10:15）。

**Q. 画面に赤いエラー「予約の読み込みに失敗… migration…」**  
→ Supabase に予約用テーブルがまだありません。下の **初回セットアップ** を1回だけ実行してください。

---

### 初回セットアップ（管理者・1回だけ）

予約機能を初めて使う前に、Supabase で SQL を1回実行します。

1. Supabase → **SQL Editor**
2. 次のファイルを開いて **全文コピー**（2本目は予約以外タブ用）  
   - `supabase/migrations/20260602120000_appointment_reservations.sql`  
   - `supabase/migrations/20260602140000_appointment_reservations_entry_kind.sql`
3. SQL Editor に貼り付け → **Run**
4. 本番画面を再読み込み

> コードの push / Vercel デプロイは済んでいれば、**SQL だけ** で使えるようになります。
