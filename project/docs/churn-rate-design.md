# 離脱・継続・再診 設計 README

> **ステータス:** v2 実装済み（本商品起点・エピソード型）  
> **表示:** アラートページ上部（`ChurnRateSummary`）＋ 経営ルール設定  
> **関連コード:** `lib/churnMetrics.ts`, `lib/churnVisitHelpers.ts`, `lib/churnConfig.ts`, `lib/churnContractType.ts`

---

## 1. 目的

- **A:** 本商品（BE）購入者をフラットに測り、早期離脱を見える化
- **B:** 契約タイプごとに「何を測るか」を分ける（混ぜない）
- **C:** 最終回マーク後の再診率（エピソード型）

**除外キーワードは経営ルール `exclude_keywords` のみ。** コード側で勝手に足さない。

---

## 2. 用語

| 用語 | 意味 |
|------|------|
| **離脱（運用）** | 最終来院から N 日 → アラート B1/B2/B3 |
| **離脱（分析 A）** | 本商品購入後、窓内に来院なし |
| **継続購入（B-2/B-3）** | 終了後に商品を再購入した割合 |
| **再診率（C）** | 最終回マーク後に再診 or 本商品再購入 |

---

## 3. 共通ルール

### 3.1 通院カウント除外

- `exclude_keywords`（例: `初`）に該当するメニューの来院のみ除外
- **初回のみの顧客**（除外後の来院ゼロ）は **すべての指標の分母から除外**

### 3.2 本商品購入（T0）

- メニュー名・取込種類・支払詳細に `churn_main_product_keywords` が含まれる最初の来院日
- 例: `BE`, `本商品`, `ボディメンテ`

### 3.3 最終回・再診

- **最終回:** `churn_final_visit_keywords`（例: `プログラム最終`, `最終回`, `卒業`）
- **再診:** `churn_revisit_keywords`（例: `再診`, `再開`）

---

## 4. 指標 A — 全体フラット

```
分母: 本商品購入者（初回のみ除外）
起点: T0 = 本商品購入日
離脱: 区間 (T0, T0+W] に来院が0回
窓: churn_windows_flat（既定 90,180）
```

6M/10M 同一物差しで「早く抜けた人」が見える。

---

## 5. 指標 B — タイプ別

### B-1 都度

- 分母: 本商品購入時に都度と判定された人
- 離脱: A と同じ（購入日起点）
- 窓: `churn_windows_single`

### B-2 回数券（消化後の再購入率）

- 分母: 回数券成約者で **最終回マークあり**
- 起点: 最終回の来院日
- 分子: 終了後 W 日以内に 都度/券/プログラム/本商品/再診 のいずれか
- 窓: `churn_windows_post_ticket`

### B-3 プログラム（終了後の継続購入率）

- 期間中の来院率は測らない（来て当たり前）
- 分母: プログラム成約者で終了日が確定（最終回マーク or 想定期間）
- 起点: 終了日
- 分子: 終了後 W 日以内に再購入
- 窓: `churn_windows_post_program`
- 6M / 3M / 10-12M はサブ区分で別表示

---

## 6. 指標 C — 再診率

```
分母: 最終回メニューが付いた来院（エピソード終了）
分子: 最終回から W 日以内に再診キーワード or 本商品再購入
窓: churn_windows_revisit
```

---

## 7. 経営ルールキー

| rule_key | 既定例 |
|----------|--------|
| `exclude_keywords` | `初`（ユーザー設定のみ） |
| `churn_main_product_keywords` | `BE,本商品,ボディメンテ` |
| `churn_program_keywords` | `6M,6ヶ月,プログラム,...` |
| `churn_final_visit_keywords` | `プログラム最終,最終回,卒業,終了` |
| `churn_revisit_keywords` | `再診,再開,リピート再開` |
| `churn_windows_flat` | `90,180` |
| `churn_windows_single` | `90,180` |
| `churn_windows_post_ticket` | `90,180,365` |
| `churn_windows_post_program` | `90,180,365` |
| `churn_windows_revisit` | `90,180,365` |
